# Pokemon Video Game Championship Elo rating histories

Pokemon Video Game Championship Elo rating histories

## Usage

``` r
pokemon_elo
```

## Format

A data frame with 2,043 rows and 4 columns:

- player_id:

  Stable player identifier

- player_name:

  Player display name

- date:

  Date of the rated event

- rating:

  Estimated Elo rating after the event

## Source

Match data compiled by VGC History, <https://vgchistory.com/data>

## Details

Elo is estimated from the available match archive and is not an official
ranking. Coverage varies across events.
