# Recent Pokemon VGC World Champions

Recent Pokemon VGC World Champions

## Usage

``` r
recent_champions
```

## Format

A data frame with 5 rows and 3 columns:

- year:

  Championship year

- player_id:

  Stable player identifier

- player_name:

  Player display name

## Source

VGC History, <https://vgchistory.com/>

## Details

The 2026 champion has no rows in `pokemon_elo` because the rating
snapshot does not include their history.
